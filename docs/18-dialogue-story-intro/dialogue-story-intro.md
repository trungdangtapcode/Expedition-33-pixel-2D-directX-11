# Dialogue Story Intro

## Summary

This feature adds a V1 story beat to the overworld: the player starts in a
Paris-inspired square, talks to Maelle, then leaves by the eastern boulevard.
The implementation is intentionally small and data-driven:

- `OverworldNpc` renders a passive NPC through `SceneGraph`.
- `DialogueState` runs linear dialogue as an overlay over frozen overworld
  gameplay.
- `DialogueManager` loads JSON scripts and resolves localized text.
- `data/overworld_npcs.json` owns NPC placement, dialogue paths, and route
  block tuning.
- `patches/compile_assets.py` and `patches/generate_map.py` regenerate the
  expanded tile atlas and Tiled-compatible overworld map.

## Runtime Flow

`OverworldState` loads NPC data after campfires and static props. Each NPC is
spawned into `SceneGraph`, so animation and Y-sorted rendering follow the same
path as player, enemy, campfire, and static prop entities.

When the player stands near Maelle, `OverworldState` shows the localized
interaction prompt from `overworld.prompt.talk`. Pressing `E` pushes
`DialogueState` with the active script path. `DialogueState` returns
`ShouldRenderBelow() == true`, which keeps the overworld visible underneath
while only dialogue updates.

When the dialogue ends, `DialogueState` sets the script `completionFlag` in
`GameProgress` and broadcasts `dialogue_completed`. The Maelle NPC uses that
flag to switch from the intro script to the repeat script.

## Route Gate

Maelle has a data-driven route block in `data/overworld_npcs.json`. Until
`dialogue_completed:intro_maelle` exists in `GameProgress`, walking into the
authored block rectangle pushes the player back to the configured pushback
position and shows `overworld.prompt.talk_to_maelle`.

The gate exists to make the opening story readable without adding a full quest
system. It should stay short and spatially obvious. Do not use this as a
general invisible wall system for every map route.

## Dialogue Data

Dialogue scripts live in `data/dialogues/*.json`.

```json
{
  "id": "intro_maelle",
  "completionFlag": "dialogue_completed:intro_maelle",
  "skippable": false,
  "lines": [
    {
      "speakerId": "Maelle",
      "speakerKey": "party.member.Maelle",
      "speakerName": "Maelle",
      "textKey": "dialogue.intro_maelle.maelle_1",
      "text": "Fallback English text."
    }
  ]
}
```

Rules:

- `speakerKey` and `textKey` are resolved through `LocalizationManager`.
- `speakerName` and `text` are English fallbacks only.
- Non-English copy belongs in `data/localization/*.json`, not in C++.
- V1 is linear. Choices should be added later as a dialogue system extension,
  not as custom branching inside `OverworldState`.

## Layout

`data/dialogue_layout.json` owns the panel size, bottom offset, text offsets,
text scale, prompt placement, reveal speed, and SFX ids. `DialogueRenderer`
uses the currently selected language font from `LocalizationManager`, so
Vietnamese text renders with the Vietnamese-capable sprite font.

The dialogue panel currently reuses:

- `assets/UI/pause_menu_panel.png`
- `assets/UI/pause_menu_panel.json`

This keeps UI style consistent while avoiding another hardcoded rectangle.

## Map And Asset Generation

The opening square is generated by:

```bat
python patches\compile_assets.py
python patches\generate_map.py
```

`compile_assets.py` now generates `overworld_tiles_v2.png` at `512x320`, which
contains 40 ground tiles. Tile IDs 33-40 are Paris cobblestone variants.

`generate_map.py` uses the same tile ID contract:

- ground tiles: firstgid `1`, tilecount `40`
- object tiles: firstgid `41`, tilecount `64`
- `ParisPlaza` is a background tile layer below entities.
- `ForegroundCanopy` remains a foreground layer because `TileMapRenderer`
  classifies layer names containing `foreground` or `canopy` as above-player.

Regenerate both assets and map JSON together. Changing `GROUND_TILE_COUNT`
without regenerating the map breaks object tileset IDs.

## Optional AI Art Reference

The committed assets are deterministic Pillow outputs. A future art pass can
use generated images as reference only, then convert them into clean sliced
atlases.

Reference prompt:

```text
Create a top-down 64x64 pixel-art tileset reference for a ruined Belle Epoque
Paris square in a dark fantasy JRPG. Include cobblestone plaza tiles, cracked
stone variants, ash-dusted boulevard edges, small flower debris, and subtle
gold-gray color accents. Orthographic top-down only, no isometric buildings,
no perspective tilt, no UI text, no characters, no camera blur, transparent
background where possible, crisp pixel-art shapes suitable for slicing into
64x64 tiles.
```

## Testing

Build:

```bat
.\build_src_static.bat 2>&1
```

Expected tail:

```text
[OK] Build succeeded > bin\game.exe  [Debug]
```

Manual smoke test:

- Start a new game and confirm the opening area is the Paris square.
- Stand near Maelle and confirm the `E` prompt appears.
- Press `E` and confirm the dialogue panel opens over frozen overworld.
- Confirm text reveals over time and Enter or Space advances lines.
- Try leaving east before talking to Maelle and confirm the gate redirects the
  player.
- Finish the dialogue and confirm the eastern route no longer redirects.
- Reopen Maelle dialogue and confirm the repeat script is used.
- Switch to Vietnamese and confirm the new text uses full diacritics.
