# Cutscene Story Expansion

## Purpose

This pass adds lightweight data-driven cutscene staging to the overworld story flow. Dialogue remains reusable and linear, while `StoryDirector` can now queue timed commands that `OverworldState` executes safely over multiple frames.

## Architecture

`StoryDirector` still does not own gameplay state. It only evaluates triggers and queues `StoryCommand` values.

`OverworldState` owns runtime execution because it has the player, camera, battle transition, and state stack. A local command queue preserves order across pushed states such as `DialogueState` and `BattleState`.

## New Story Commands

The following command types are supported in `data/story_events.json`:

- `set_player_control`: disables or enables overworld player control.
- `move_player`: interpolates the player to `x`, `y` over `duration` seconds.
- `focus_camera`: interpolates the camera to `x`, `y` over `duration` seconds.
- `wait`: pauses the command chain for `duration` seconds.

Existing commands still work:

- `start_dialogue`
- `start_battle`
- `recruit_member`
- `set_flag`
- `save_checkpoint`
- `push_player`
- `grant_coins`
- `grant_item`

## Command Queue Rules

Synchronous commands run immediately until a blocking command appears. Blocking commands include timed cutscene steps, dialogue pushes, and battle transitions.

Commands after `start_dialogue` remain queued. When the dialogue state pops, `OverworldState` resumes the same command queue before evaluating new area triggers.

## Current Story Expansion

The Maelle confrontation now stages the scene before dialogue:

1. Disable player control.
2. Focus camera on Maelle.
3. Move Verso to the confrontation mark.
4. Wait briefly.
5. Start confrontation dialogue.
6. Restore control after the dialogue state closes.

The post-duel reconciliation also uses camera focus and a short pause before dialogue.

After Maelle joins, the route now points to the western watch before returning to the silent market. This uses the existing generated map pipeline and adds a connector path plus extra static props.

## Map Pipeline

The route expansion is generated by `patches/generate_map.py`.

Outputs:

- `assets/environments/overworld_map.json`
- `data/overworld_props.json`

Do not hand-edit generated Tiled JSON unless the generator cannot express the intended layout. If the route changes, update the generator and regenerate.

## Authoring Guidelines

- Use `focus_camera` before a dialogue if the player needs to see who or what matters.
- Use `move_player` sparingly; it should stage a scene, not replace player traversal.
- Always restore player control after a cutscene chain unless the next command starts a battle or pushes another state.
- Put all player-facing text in localization JSON, not in C++ or dialogue script fallbacks.
- Keep route objectives aligned with enemy spawn gates so the beacon always points at reachable content.
